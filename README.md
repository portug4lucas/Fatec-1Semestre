# Fatec Jacareí — 1º Semestre

Atividades e projetos desenvolvidos durante o primeiro semestre do curso de **Desenvolvimento de Software Multiplataforma (DSM)** na Fatec Jacareí.

## Projetos

- **Fatec-Algoritmos-Typescript** — Exercícios de algoritmos e lógica de programação
- **Fatec-Algoritmos-Typescript2** — Exercícios de algoritmos e lógica de programação
- **Fatec-Cadastro-De-Usuario** — Sistema de cadastro de usuário
- **Fatec-Cadastro-Megasena** — Cadastro de apostas da Megasena
- **Fatec-Consulta-De-Cep** — Consulta de CEP via API
- **Fatec-Resultados-Megasena** — Resultados da Megasena via API
- **Fatec-Site-ODS** — Site sobre os ODS da ONU
- **Fatec-Typescript** — Exercícios de TypeScript

## Tecnologias

TypeScript · JavaScript · HTML · CSS · Node.js · PostgreSQL
