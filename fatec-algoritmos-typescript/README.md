# Fatec — Algoritmos em TypeScript

Exercícios práticos de algoritmos e lógica de programação desenvolvidos em TypeScript.

Feitos para praticar

---

## 📋 Pré-requisitos

Antes de rodar o projeto, você precisa ter instalado:

- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- npm (já vem junto com o Node.js)

Para verificar se já estão instalados:

```bash
node -v
npm -v
```

---

## 🚀 Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/portug4lucas/fatec-algoritmos-typescript.git
cd fatec-algoritmos-typescript
```

### 2. Instale as dependências

```bash
npm install
```

### 3. Instale o TypeScript globalmente (caso não tenha)

```bash
npm install -g typescript
```

Para verificar se foi instalado corretamente:

```bash
tsc -v
```

---

## ▶️ Como rodar os exercícios

Cada exercício pode ser executado individualmente com os scripts do npm:

```bash
npm run um    # Exercício 1 — Detector de Palíndromos
npm run dois  # Exercício 2 — Analisador de Senhas
npm run tres  # Exercício 3 — Catálogo de Criaturas Fantásticas
npm run quatro  # Exercício 4 — Simulador de Fila de Atendimento
npm run cinco   # Exercício 5 — Decifrador de Mensagens Secretas
npm run seis    # Exercício 6 — Ranking de Jogadores
npm run sete    # Exercício 7 — Validador de CPF Simplificado
npm run oito    # Exercício 8 — Gerador de Estatísticas de Texto
npm run nove    # Exercício 9 — Sistema de Missões de RPG
npm run dez     # Exercício 10 — Compactador de Texto
```

---

## 📁 Exercícios

| # | Nome | Descrição |
|---|------|-----------|
| 1 | Detector de Palíndromos | Verifica se uma palavra ou frase é um palíndromo |
| 2 | Analisador de Senhas | Analisa a força e os critérios de uma senha |
| 3 | Catálogo de Criaturas Fantásticas | Gerencia um catálogo de criaturas com TypeScript |
| 4 | Simulador de Fila de Atendimento | Simula uma fila de atendimento com prioridades |
| 5 | Decifrador de Mensagens Secretas | Decifra mensagens codificadas |
| 6 | Ranking de Jogadores | Ordena e exibe um ranking de jogadores |
| 7 | Validador de CPF Simplificado | Valida CPFs usando algoritmo de dígitos verificadores |
| 8 | Gerador de Estatísticas de Texto | Analisa e gera estatísticas de um texto |
| 9 | Sistema de Missões de RPG | Gerencia missões e status de personagens |
| 10 | Compactador de Texto | Compacta textos usando algoritmo de repetição |
