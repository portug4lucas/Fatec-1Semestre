## ▶️ Como rodar localmente

**1. Clone o repositório:**
```bash
git clone https://github.com/portug4lucas/atividade-site-consulta-cep.git
cd atividade-site-consulta-cep
```

**2. Instale as dependências:**
```bash
npm install
```

**3. Crie o arquivo `.env` na raiz do projeto:**
```env
PORT=3001
```

**4. Inicie o servidor:**
```bash
node server.js
```
